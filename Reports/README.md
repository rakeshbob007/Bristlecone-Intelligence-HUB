# Reports

Auto-generated BCONHUB reports land here, one per report run.

**Naming pattern:** `BCONHUB-Report_<YYYY-MM-DD>_<HHMMSS>.html`
Example: `BCONHUB-Report_2026-09-11_143205.html`

See [`../Instructions.md`](../Instructions.md) for the generation rules and [`../report-template.html`](../report-template.html) for the reusable design these reports are built from.
